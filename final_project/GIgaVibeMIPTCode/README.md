# GigaVibeMIPTCode

Консольный чат-клиент для взаимодействия с LLM (Large Language Model), реализованный на Python.

Проект поддерживает локальные OpenAI-совместимые модели (например, Ollama), хранение истории сообщений, обработку файлов и режим почанковой обработки больших текстов.

## Быстрый старт

### 1. Клонировать репозиторий

### 2. Установить зависимости

```bash
python -m pip install openai
python -m pip install pyyaml
python -m pip install types-pyyaml
python -m pip install pytest
python -m pip install pytest-cov
python -m pip install mypy
python -m pip install ruff
```

### 3. Настроить конфигурацию

Создать файл:

```text
resources/config.yaml
```

и заполнить его:

```yaml
api_key: ollama

api_host: http://localhost:11434/v1/

model: gemma3:270m

limit_message: 20

limit_characters: 4000

temperature: 0.3

system_prompt: |
  You are a helpful assistant
```

При использовании локальных моделей через Ollama:

Скачать модель:

```bash
ollama pull gemma3:270m
```

Запустить Ollama:

```bash
ollama serve
```

---

### 4. Запустить приложение

Из корневой папки проекта:

```bash
python -m src.main.main
```
---

## Основной функционал

### Работа с LLM

- взаимодействие с OpenAI-совместимыми API;
- поддержка локальных моделей через Ollama;
- настройка модели через конфигурационный файл и переменные окружения;
- системный промпт (system prompt);
- история сообщений;
- ограничение истории:
  - по количеству сообщений;
  - по количеству символов.

| Команда | Описание |
|----------|-----------|
| `\q` | выход из приложения |
| `/reset` | очистка истории чата |

```text
В чем ошибка в коде? @::Main.java::
```

## Команда `/file_chunk`

Режим `/file_chunk` используется для обработки больших файлов, которые не помещаются в контекст модели целиком.

Поддерживаемые режимы:

### Разделение по одному абзацу

```text
/file_chunk
```

### Разделение по нескольким абзацам

```text
/file_chunk paragraph=3
```

### Разделение по длине

```text
/file_chunk len=1000
```

### Автоматическая обработка

```text
/file_chunk -y
```

Флаг `-y` отключает ожидание Enter между обработкой частей.

### Пример использования

```text
>>> /file_chunk

Введите путь до файла
>>> C:\Users\user\main.py

Что нужно сделать для каждого фрагмента?
>>> Объясни что происходит в коде
```
